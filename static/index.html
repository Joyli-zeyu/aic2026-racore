01 / 核心创新

风险感知压缩与精炼框架

传统方法对密集特征金字塔中的所有体素一视同仁，RaCoRe 把「哪些体素值得仔细处理」交给模型自己学—— 风险由此从事后指标变成表征组织的先验准则。

M1

RAIM · 区域自适应输入调制

编码器前端施加有界（≤0.05）空间变化修正，深度可分离卷积提取结构，sigmoid 门控生成空间注意力，按区域重校准多模态 MRI 通道——让输入本身先聚焦到关键区域。

X̃ = X + αin · φm(S ⊙ G)
M2

MTRE · 多尺度任务风险估计

从 1/16、1/8、1/4 三个编码器层级分别估计任务风险，以复合 Dice-Focal 目标监督前景、关键结构与边界，使风险图同时具备全局语义与局部精度。

Rs = clip(σ(Fs), 0, 1), s ∈ {1/16, 1/8, 1/4}
M3

RSMC · 风险分层记忆压缩

密集特征按高 / 中 / 低风险分为三组，经加权自适应池化压缩为共 749 个 memory token——高风险区域保留更多表征预算，背景压缩为极少量 token，存储开销仅 O(d·T)。

P(V,W;q) = AAPq(V⊙W) / max{AAPq(W), ε}
M4

MCBA · 记忆条件瓶颈适配

以通道级调制读取压缩记忆，更新最深宿主特征；对 token 型主干可切换为有界交叉注意力读写——参数高效地把风险记忆注入主干瓶颈层。

F' = F + γ · MLA(F, M), γ ∈ [0, 1]
M5

CCDR · 上下文校准细节精炼

在 1/8 与 1/4 解码阶段以 5×5×5 深度可分离算子精炼细节，残差经 sigmoid 约束，逐级校准上下文——边界预测更贴近真实解剖轮廓。

D' = D + σ(β) · Φ5×5×5(D)
∞

主干无关的可复用增强

CNN、Transformer、状态空间（Mamba）、KAN 四类主干共享同一接口：五个模块以残差形式介入，训练从接近宿主的状态出发，新增参数量小，宿主既有能力不丢失。
